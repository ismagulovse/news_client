# Разбор ядра новостного клиента

Этот файл объясняет текущий код приложения: от запуска до получения новостей, сохранения кэша и работы с избранным. Читать лучше по порядку, открывая рядом соответствующий Dart-файл. Примеры взяты из проекта; в некоторых местах изменены только переносы строк.

## 1. Как связаны основные части

```text
main.dart — запускает приложение
    ↓
NewsScreen — создаёт экран и состояние
    ↓
NewsState — решает, что и когда загружать
    ↓
NewsRepository — получает данные и создаёт объекты Article
    ↓
NewsApi — отправляет запрос к GNews

NewsState → NewsStore → локальный кэш
FavoritesState → NewsStore → сохранённое избранное
```

Ответ возвращается в обратном порядке: API → repository → состояние → экран.
Экран рисует виджеты, а отдельные классы занимаются запросами и хранением данных.

## 2. Запуск — main.dart

Файл: `lib/main.dart`.

```dart
void main() {
  runApp(const MyApp());
}
```

`main()` — первая функция программы. `runApp()` сообщает Flutter, какой виджет нужно показать.

В `MyApp` создаётся `MaterialApp`. Он задаёт название, тему и начальный экран:

```dart
home: const NewsScreen(),
```

Запросов к API здесь нет. Этот файл нужен только для запуска и общих настроек интерфейса.

## 3. Данные новости — Article и Source

Файлы: `lib/models/article.dart` и `lib/models/source.dart`.

`Article` — класс, описывающий одну статью. Каждый объект содержит свои данные:

| Поле | Что хранит |
|---|---|
| `title` | Заголовок |
| `text` | Краткое описание |
| `content` | Доступный текст статьи |
| `image` | Ссылку на изображение |
| `url` | Ссылку на оригинал статьи |
| `date` | Дату публикации или `null` |
| `source` | Объект источника с названием и адресом |

Поля объявлены через `final`: после создания статьи им нельзя присвоить другие значения.

### Из ответа API в объект

API присылает JSON — текст с данными. После его разбора отдельная статья представлена набором пар «ключ — значение». Метод `Article.fromJson()` создаёт из них объект:

```dart
title: json['title'] ?? '',
text: json['description'] ?? '',
```

`json['title']` получает значение по ключу `title`. Оператор `??` означает: если значение равно `null`, использовать правую часть. В этом примере — пустую строку.

`factory` перед `Article.fromJson` обозначает специальный конструктор. Здесь он собирает и возвращает новый `Article`.

```dart
date: DateTime.tryParse(json['publishedAt'] ?? ''),
```

`tryParse()` пытается превратить строку в дату. Если строка неподходящая, возвращает `null`. Поэтому тип поля — `DateTime?`: знак `?` разрешает отсутствие даты.

### Обратно в JSON

`toJson()` делает обратное преобразование: объект статьи превращается в набор значений. Это нужно для сохранения кэша и избранного.

`dateText` — getter, то есть вычисляемое свойство. При обращении к `article.dateText` код переводит дату в местное время и собирает строку вида `29.10.2026`.

## 4. Запрос к серверу — NewsApi

Файл: `lib/data/news_api.dart`.

Основной метод — `getNews()`. Он принимает:

| Параметр | Значение по умолчанию | Назначение |
|---|---|---|
| `page` | `1` | Номер страницы |
| `category` | `'general'` | Категория |
| `searchText` | `''` | Текст поиска |

Параметры в фигурных скобках называются именованными. При вызове видно, что именно передаётся:

```dart
api.getNews(page: 2, category: 'science', searchText: 'космос');
```

Ключ читается из параметров сборки:

```dart
const apiKey = String.fromEnvironment('GNEWS_KEY');
```

Сам этот код не открывает `config.json`. Файл передаётся Flutter при запуске через `--dart-define-from-file=config.json`. Если параметр запуска пропущен, ключ будет пустым.

`Uri.https()` собирает адрес запроса. В параметры передаются язык `ru`, размер страницы `10`, номер страницы и категория. Поле `q` добавляется только при непустом поиске.

```dart
response = await http.get(url).timeout(const Duration(seconds: 30));
```

`http.get()` отправляет запрос. `await` ждёт его завершения внутри этого метода, позволяя приложению продолжать обрабатывать другие события. `timeout` ограничивает ожидание 30 секундами.

Текущий код отдельно обрабатывает превышение времени ожидания и `http.ClientException`. Сообщение «Нет интернета» здесь общее: `ClientException` также может возникнуть из-за ограничений браузера или другой проблемы соединения.

После получения ответа проверяется `statusCode`. Код `200` означает успешный HTTP-ответ. Другой код превращается в `NewsError`.

```dart
final data = jsonDecode(response.body);
return data['articles'];
```

`jsonDecode()` разбирает текст ответа. Метод возвращает содержимое поля `articles`, пока ещё без преобразования в `Article`.

`NewsError` находится в `lib/data/news_error.dart`. Это маленький класс ошибки с одним полем `message`. Он позволяет передать понятное сообщение в состояние приложения.

## 5. Преобразование ответа — NewsRepository

Файл: `lib/data/news_repository.dart`.

Repository вызывает API, затем проходит по полученным статьям:

```dart
final news = <Article>[];
for (final item in data) {
  news.add(Article.fromJson(item));
}
return news;
```

`<Article>[]` — пустой список, в котором будут объекты `Article`.
Цикл берёт один элемент ответа, создаёт статью и добавляет её в список.

Так `NewsState` получает готовый `List<Article>` и не разбирает поля JSON самостоятельно.

## 6. Основная логика — NewsState

Файл: `lib/state/news_state.dart`. Это основная часть управления лентой.

### Переменные

| Переменная | Значение |
|---|---|
| `newsRepo` | Объект для получения новостей |
| `store` | Объект для локального хранения |
| `news` | Новости, которые показываются сейчас |
| `loading` | Выполняется ли загрузка |
| `hasMore` | Можно ли попробовать следующую страницу |
| `cached` | Показана ли сохранённая лента |
| `closed` | Завершена ли работа объекта состояния |
| `page` | Последняя успешно загруженная страница |
| `category` | Выбранная категория |
| `searchText` | Применённый текст поиска |
| `error` | Ошибка основной загрузки или кэша |
| `moreError` | Ошибка загрузки следующей страницы |

### Первая загрузка и обновление

Метод `loadNews()` выполняет следующие действия:

1. Если запрос уже идёт, выходит через `return`.
2. Ставит `loading = true`, очищает сообщения об ошибках и обновляет экран.
3. Запрашивает первую страницу с текущими фильтрами.
4. Заменяет ленту полученными статьями без дублей.
5. Сбрасывает `page` до `1` и признак `cached` до `false`.
6. Сохраняет результат в кэш.
7. Завершает загрузку и снова обновляет экран.

Если запрос завершился ошибкой, метод записывает сообщение в `error`. Если список на экране пустой, он пробует прочитать кэш. При ошибке обновления уже показанные новости остаются на экране.

### Следующая страница

`loadMore()` запрашивает `page + 1`. Полученные статьи добавляются к существующим.
Номер `page` увеличивается только после успешного запроса. Поэтому после ошибки можно повторить ту же страницу.

```dart
hasMore = newNews.length == 10 && page < 100;
```

Если пришло меньше 10 статей, код считает, что лента закончилась. Полные 10 статей означают, что можно попробовать следующий запрос, но не гарантируют наличие следующей страницы. Число `100` ограничивает количество страниц в этом приложении.

При показе кэша подгрузка отключена. Сначала нужно успешно обновить ленту.

### Удаление дублей

Метод `addNews()` сравнивает статьи по `url`:

1. Берёт статью из новой порции.
2. Пропускает её, если ссылка пустая.
3. Проверяет, есть ли такая ссылка в текущем списке.
4. Добавляет статью, только если совпадений нет.

`continue` переходит к следующей новой статье. `break` заканчивает внутренний цикл, когда совпадение уже найдено.

### Поиск и категория

`filter()` меняет `category` и `searchText`, очищает старую ленту и начинает загрузку с первой страницы.
`trim()` удаляет пробелы по краям поисковой строки. Например, ` космос ` превращается в `космос`.

### Как экран узнаёт об изменениях

`NewsState` наследуется от `ChangeNotifier`. Это класс Flutter, который умеет уведомлять подписчиков.

```dart
void update() {
  if (!closed) notifyListeners();
}
```

`notifyListeners()` вызывает зарегистрированные функции. Основной экран подписан на состояние и в ответ вызывает `setState()`. Flutter заново выполняет построение интерфейса с актуальными данными.

Проверка `closed` нужна потому, что запрос может закончиться уже после закрытия экрана и освобождения состояния.

## 7. Локальное хранение — NewsStore

Файл: `lib/data/news_store.dart`.

Используется `SharedPreferences` — хранение небольших значений по ключу. В браузере данные относятся к текущему адресу сайта и профилю браузера.

### Запись и чтение

Метод `save()` переводит статьи в JSON и сохраняет строку:

```text
List<Article> → список Map → jsonEncode → строка в хранилище
```

Метод `read()` выполняет обратные действия:

```text
строка → jsonDecode → список Map → Article.fromJson → List<Article>
```

Если записи с нужным ключом нет, `read()` возвращает пустой список.

### Какие записи существуют

| Ключ | Содержимое |
|---|---|
| `favorites` | Избранные статьи |
| `cache` | Последняя сохранённая лента |
| `cache_filter` | Категория и поиск этой ленты |

`readCache()` сравнивает сохранённые фильтры с текущими. Если они разные, возвращает пустой список. Так спортивные новости не появятся вместо результатов поиска по науке.

`saveCache()` сначала удаляет старую метку фильтра, затем сохраняет новости и новую метку. Если запись новостей сорвётся, старый фильтр не будет ошибочно описывать другое содержимое кэша.

Кэш хранит только последнюю ленту, включая загруженные страницы. Отдельного кэша для каждой категории нет. Изображения в этом классе не скачиваются: сохраняются только их ссылки.

## 8. Избранное — FavoritesState

Файл: `lib/state/favorites_state.dart`.

Здесь тоже есть список `news`, но это отдельный список избранных статей.

- `load()` читает запись `favorites` при запуске.
- `contains(article)` ищет статью по ссылке и возвращает `true` или `false`.
- `toggle(article)` добавляет статью или удаляет её, если она уже была сохранена.

В `toggle()` сначала создаётся копия списка:

```dart
final newNews = List<Article>.from(news);
```

Изменения вносятся в копию. `removeWhere()` удаляет элементы, для которых условие вернуло `true`:

```dart
newNews.removeWhere((item) => item.url == article.url);
```

Затем копия сохраняется. Только после успешного сохранения она становится текущим списком `news`. Если запись не удалась, старый список остаётся.

`busy` блокирует повторные действия, пока идёт чтение или сохранение. После завершения вызывается `notifyListeners()`, чтобы обновить надписи кнопок и вкладку избранного.

## 9. Основной экран — NewsScreen

Файл: `lib/screens/news_screen.dart`.

Экран создаёт оба состояния:

```dart
final state = NewsState(NewsRepository());
final favorites = FavoritesState(NewsStore());
```

`initState()` выполняется один раз при создании состояния виджета. В нём экран подписывается на изменения и запускает загрузку новостей и избранного.

```dart
void update() {
  setState(() {});
}
```

Пустое тело здесь допустимо: данные уже изменились внутри `NewsState` или `FavoritesState`. Нужно лишь сообщить Flutter, что экран следует перестроить.

`tab` хранит номер выбранной вкладки: `0` — новости, `1` — избранное.
`IndexedStack` показывает выбранную вкладку, сохраняя остальные виджеты. Благодаря этому при переключении не создаётся заново поле поиска.

В `dispose()` экран снимает подписки и освобождает состояния. Это завершение работы виджета.

## 10. Прокрутка и обновление — NewsFeed

Файл: `lib/screens/news_feed.dart`.

`ScrollController` следит за прокруткой. Когда до конца списка остаётся меньше 300 пикселей, вызывается `state.loadMore()`.
После ошибки автоматическая подгрузка приостанавливается; пользователь может нажать «Повторить».

```dart
RefreshIndicator(
  onRefresh: state.loadNews,
  // Здесь находится список новостей.
)
```

Это фрагмент, показывающий назначение `RefreshIndicator`: жест вниз запускает тот же `loadNews()`, что и кнопка обновления. В полном коде внутрь передан список через `child`.

`AlwaysScrollableScrollPhysics` позволяет сделать жест даже при коротком или пустом списке. `ScrollConfiguration` разрешает перетаскивание мышью, что удобно в Chrome.

`ListView.builder` создаёт элементы по необходимости. Количество элементов равно `news.length + 1`: дополнительное место отведено под индикатор загрузки, сообщение или кнопку следующей страницы.

Первая карточка получает `isMain: true` и отображается крупнее остальных.

## 11. Поиск, карточка и открытие статьи

`lib/widgets/news_filters.dart` содержит поле поиска и чипы. `TextEditingController` хранит введённый текст. `onFilter` — переданная функция: основной экран передаёт туда `state.filter`. Поэтому виджет может сообщить о выборе категории, не выполняя сетевой запрос сам.

В словаре `categories` английское имя отправляется API, а русское показывается пользователю. Чип «Все» в текущем коде соответствует категории GNews `general`.

`lib/widgets/news_card.dart` показывает данные одной статьи. Нажатие вызывает `Navigator.push()` и открывает `ArticleScreen` с уже загруженным объектом. Повторный запрос текста не выполняется.

`lib/screens/article_screen.dart` показывает описание и доступное содержимое статьи. Длинный текст прокручивается. Кнопка источника вызывает `launchUrl()` со ссылкой на оригинал.

`ListenableBuilder` на экране статьи слушает избранное и обновляет кнопку при его изменении. Проверка `context.mounted` перед сообщением об ошибке означает: виджет всё ещё существует после ожидания операции.

## 12. Конструкции Dart, которые встречаются чаще всего

| Конструкция | Простое объяснение |
|---|---|
| `final` | Переменной присваивают значение один раз; содержимое списка при этом может меняться |
| `const` | Значение известно заранее, при компиляции |
| `required` | Этот именованный параметр обязательно передать |
| `Future<T>` | Результат типа `T` будет получен позже |
| `Future<void>` | Операция завершится позже, но значения не вернёт |
| `async` | В методе можно использовать `await` |
| `await` | Дождаться результата асинхронной операции |
| `try/catch` | Выполнить операцию и обработать исключение |
| `throw` | Сообщить об ошибке, прервав обычное выполнение |
| `if/else` | Выбрать действие по условию |
| `??` | Подставить другое значение вместо `null` |
| `?.` | Обратиться к свойству или методу, только если объект не `null` |
| `=>` | Короткая запись функции с одним выражением |
| `@override` | Метод переопределяет метод родительского класса |

`if/else` не заменяет `try/catch`: условие проверяет уже полученные данные, а `catch` обрабатывает ошибку самой операции. Например, HTTP-ответ можно проверить через `if`, но при обрыве соединения ответа может вообще не быть.

## 13. Как объяснить работу приложения на защите

При запуске основной экран создаёт состояние и просит загрузить новости. Состояние обращается к repository, который вызывает API и преобразует JSON в статьи. Полученный список сохраняется в состоянии и в локальном кэше. Состояние уведомляет экран, и Flutter перестраивает список карточек.

При прокрутке запрашивается следующая страница; повторяющиеся ссылки не добавляются. При поиске или выборе категории список начинается заново. Обновление жестом повторно загружает первую страницу. Если сеть недоступна и список пустой, приложение пробует показать кэш с такими же фильтрами.

Избранное хранится отдельно. Добавление или удаление статьи сначала сохраняется локально, затем обновляются экран и кнопки. Полный оригинал новости открывается по ссылке на сайте источника.
