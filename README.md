# Новостной клиент — лабораторная № 7

## Запуск

В локальном файле `config.json` должно быть поле `GNEWS_KEY` с ключом GNews.
Файл исключён из Git. В VS Code выбери «Новости (Chrome)» и нажми F5.
После изменения ключа или добавления пакетов полностью останови и запусти приложение.

```powershell
flutter run -d chrome --web-port=7357 --dart-define-from-file=config.json
```

Постоянный порт нужен для сохранения данных браузера между запусками.
Кэш и избранное принадлежат текущему профилю браузера и адресу сайта.

## Функции

- Поиск кнопкой «Найти» или Enter, сброс поиска.
- Категории в виде чипов. Поиск учитывает выбранную категорию.
- По 10 статей на страницу. При прокрутке загружается следующая страница.
- Кнопка «Загрузить ещё» позволяет продолжить и при коротком списке.
- Обновление жестом вниз от начала ленты или кнопкой «Обновить».
- Нажатие на карточку открывает статью, кнопка источника — её оригинал.
- Нижнее меню «Новости» и «Избранное» без иконок.
- Избранное сохраняется локально и доступно без запроса к API.

Бесплатный GNews отдаёт сокращённый текст. Полная статья открывается у источника.
Пагинация относится к ленте; текст одной статьи прокручивается.

## Кэш

После успешного запроса сохраняется последняя загруженная лента с её категорией
и поисковой строкой. Если запрос не удался, приложение показывает этот кэш,
только если фильтры совпадают. Кэш другой категории не подставляется.
Изображения отдельно не сохраняются. Само веб-приложение должен отдавать
локальный сервер Flutter; это не установка сайта для полностью автономного запуска.

## Файлы

- `models` — данные статьи и источника.
- `data/news_api.dart` — HTTP-запросы.
- `data/news_repository.dart` — перевод ответа в список статей.
- `data/news_store.dart` — чтение и сохранение кэша и избранного.
- `state/news_state.dart` — загрузка, фильтры и страницы.
- `state/favorites_state.dart` — добавление и удаление избранного.
- `screens` — основной экран, лента, избранное и статья.
- `widgets` — карточки, изображения, поиск и кнопка избранного.

## Проверка

```powershell
flutter analyze
flutter test
```

Вручную: загрузить ленту, прокрутить вниз, обновить, найти статью,
выбрать категорию, открыть статью и источник. Добавить статью в избранное,
переключить вкладку, перезапустить приложение и проверить сохранение.
Для кэша: загрузить новости, отключить сеть и обновить ту же ленту.
